# my-zed

Personal Zed config: vim mode with keybindings ported from [my-neovim](https://github.com/adavila0703/my-neovim).

- `settings.json`: editor settings
- `keymap.json`: keybindings (leader = space)
- `tasks.json`: tasks used by the keymap (lazygit)

## Install

Linux / macOS (Zed reads `~/.config/zed`):

```sh
git clone git@github.com:adavila0703/my-zed.git ~/.config/zed
```

If `~/.config/zed` already exists, move it out of the way first.

Windows: Zed's config lives in `%APPDATA%\Zed`. Clone there instead.
